# FAQ Chatbot

## Description
This is a simple FAQ Chatbot developed using Python. It answers user questions by comparing the input with predefined questions stored in a JSON file using TF-IDF Vectorization and Cosine Similarity.

## Features
- Answers frequently asked questions
- Uses JSON file as a knowledge base
- TF-IDF based text matching
- Cosine Similarity for finding the best answer
- Simple command-line interface

## Technologies Used
- Python
- Scikit-learn
- JSON

## Project Files
- faq_chatbot.py
- faq_data.json
- FAQ_Chatbot_Output.png

## How to Run
1. Install the required libraries.
2. Open the project folder in VS Code.
3. Run:
   ```
   python faq_chatbot.py
   ```
4. Type your question.
5. Type `exit` to quit the chatbot.

## Output
The chatbot successfully answers user questions based on the FAQ dataset.
